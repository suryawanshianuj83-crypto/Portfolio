Maatri.ai

A prototype for maternal health risk assessment.

Problem

Maternal health risk is judged from a small set of routine readings. This prototype asks a practical question: can a trained model turn those readings into a clear Low, Mid or High risk level?

Solution

A Flask web app wraps a trained Random Forest classifier. A user enters six health readings and gets a predicted risk level along with a probability for each category.

Technology

Python and Flask serve the app. A Random Forest model with standardized features does the prediction. A JSON endpoint, /api/predict, allows programmatic access. The interface is plain HTML, CSS and JavaScript.
